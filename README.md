# GNG Vercel Site V2

This is a deployable Next.js website package for GNG New Tech LLC.

## Pages included
- Home: `/`
- About: `/about`
- Products: `/products`
- Contact: `/contact`

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Upload this folder to a new GitHub repository.
2. In Vercel, click **Add New → Project**.
3. Import the GitHub repository.
4. Deploy with the default Next.js settings.
